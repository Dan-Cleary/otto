zoom integration

otto's zoom integration reads cloud-recording transcripts from connected zoom accounts so it can extract code-shaped action items and open draft pull requests on github. otto never joins meetings, never stores audio or video, and is read-only on zoom's side.

add otto to your zoom account

  1. sign in at ottoagent.app/login with the email you want to administer otto under
  2. go to the onboarding tab
  3. step 03 — click connect with zoom
  4. you'll be sent to zoom's consent screen. review the requested scopes (all read-only) and click allow
  5. zoom redirects you back to otto. you should see connected as <your email> in step 03

only zoom account admins can install this app — it is admin-managed and accesses recordings across the account.

what otto reads

  • cloud recording transcripts — the auto-generated text transcript only. otto does not download audio or video.
  • ai companion meeting summaries — for meetings that were not cloud-recorded but had ai companion enabled.
  • meeting metadata — title, host, scheduled time. used to attribute the source meeting in each draft pr.
  • account user list — used only to know whose recordings to ingest. otto never modifies, creates, or deletes users.

scopes requested

  • cloud_recording:read:list_user_recordings:admin
  • cloud_recording:read:recording:admin
  • cloud_recording:read:meeting_transcript:admin
  • meeting:read:meeting:admin
  • meeting:read:summary:admin
  • user:read:list_users:admin

no write scopes. otto cannot post messages, modify recordings, change settings, or take any action inside zoom.

how transcripts flow into pull requests

  1. zoom finishes generating a transcript and fires a recording.transcript_completed webhook to otto
  2. otto fetches the transcript text and the meeting metadata
  3. otto's parser pulls out code-shaped action items ("can we change x to y", "we should add a button for z")
  4. each action item is routed to the right github repository based on your project configuration
  5. otto opens a draft pull request with the proposed change, the original transcript excerpt, and a confidence score
  6. low-confidence items go to a slack review queue instead of auto-firing a pr

otto also runs a 5-minute polling backstop in case a webhook is dropped — same flow, just initiated by cron.

data retention

  • transcripts are stored encrypted at rest in our convex database
  • retention follows the plan you choose under settings → retention in otto (default 30 days)
  • removing the integration deletes all stored transcripts associated with the integration within 24 hours
  • account-level deletion is available on request to support@ottoagent.app

remove otto from your zoom account

  1. sign in to marketplace.zoom.us as a zoom account admin
  2. go to manage → added apps
  3. find otto and click remove
  4. also disconnect inside otto: onboarding → step 03 → disconnect

once removed, otto immediately stops polling and discards stored zoom tokens. transcripts already ingested are retained per your retention policy unless you also request deletion.
